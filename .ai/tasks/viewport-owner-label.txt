# 任务

类型：bug
状态：done
创建：2026-09-11

一句话描述：桌面端接管占位只显示通用「平板/手机」，不显示控制方设备型号/名称。

## 等级

grade：Guarded
依据：跨 host（desktop / agent）到 controller 的 viewport-state 共享 wire 契约，以及 `TerminalEvent::Viewport` 事件字段；多文件、多调用点。
升级触发证据：本任务触及跨产品 JSON 契约与共享事件枚举；新增 payload 测试在未修改版本失败。

## Active Contract

state：frozen

### 目标

当另一台设备（手机/平板）持有桌面端正在查看的远程项目终端 viewport 时，桌面端接管占位显示该设备的真实名称/型号（如设备已登记），不再退化为按 grid 长宽比推断的通用「平板/手机」。设备名称未知时可保持现有通用回退。

### 证据

复现（未修改版本，A）：新增测试 `apps/desktop/runtime/src/remote/host/tests/terminal_viewport.rs::viewport_state_payload_includes_owner_label` 断言 `terminal_viewport_state_payload(...)["ownerLabel"] == "Pixel 9"`；未修改版本该 key 不存在，测试失败。

因果链：
1. desktop-as-controller 场景下，桌面 pane 的 `viewport_owner_label()` 读 `HostedViewportAuthority.state.owner_label`（`apps/desktop/src/terminal/pane.rs:1356`）。
2. 该 state 只由 controller 转发的 `TerminalEvent::Viewport` 更新；`TerminalEvent::Viewport` 没有 label 字段（`crates/codux-terminal-core/src/terminal_driver.rs:64-71`）。
3. host 侧 `terminal_viewport_state_payload`（desktop，`terminal_buffer.rs:126`）与 `viewport_state_payload`（agent，`terminals.rs:517`）都不发送 `ownerLabel`。
4. 因此 controller 端 `owner_label` 恒为 `None`；`render.rs:83` 回退到按 `model_rows >= model_cols` 推断的 `terminal.handoff.phone/tablet` → 用户只看到「平板」。
5. host 侧其实已具备设备名称来源：desktop `RemoteHostRuntime::device_name_for`（cached_devices），agent `device_store`（PairedDevice.name），且 `state.owner` 编码 `remote:<device_id>`。

first-wrong：viewport-state wire payload 缺 `ownerLabel`，且 `TerminalEvent::Viewport` 不承载该值，controller 无法把 host 已知的设备名送到接管占位。

现有正确路径证据（Guarded 前置）：
- host 本地（desktop-as-host）路径已有正确实现：`handle_terminal_viewport_claim` / `resize_terminal_viewport_from_envelope` 调 `set_viewport_owner_label(session_id, owner, device_name_for(device_id))`，本地 pane 的 `viewport_owner_label()` 能取到名称。缺的只是把它送到远端 controller。
- 设备名来源已有：desktop `device_name_for` 查 `cached_devices`；agent `device_store::list()` 的 `PairedDevice.name`。
- `state.owner` 已有稳定格式 `remote:<device_id>`（`terminal_viewport_remote_owner`），无需新增标识机制。
- 该 payload 为 JSON，新增可选字段向后兼容：旧 controller 忽略新 key；缺 key 时 `None` → 现有通用回退不变。

### 授权变更

只授权一个因果单元：让 viewport owner 名称沿既有 viewport-state 通道到达桌面接管占位。最小改动：
- host：desktop / agent 的 viewport-state payload 增加 `ownerLabel`（从 `state.owner` 解析 device id，查已登记设备名；未知则 null）。
- 事件：`TerminalEvent::Viewport` 增加可选 `owner_label`，controller 解析 payload 时带入；`register_hosted_terminal` 写入 `authority.state.owner_label`。
- 不改 viewport 所有权/lease 语义、不改接管按钮逻辑、不改移动端、不新增设备名来源或注册机制。
