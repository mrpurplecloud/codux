### 边界

last-known-good：current HEAD 的 host/mobile 契约以 `terminal.viewport.state` 为权威；mobile 仅在 owner 为 `remote:<device_id>` 时交互；本地 PTY binding 从真实 session viewport state 判权。
first-wrong：desktop managed hosted attach 只保存 controller/session；没有 owner identity/authority state。随后 `local_viewport_owns()` 因 local session 为空走 `unwrap_or(true)`，`write()`/`resize()` 无条件调用 controller。
方法：current source 调用链复验 + 隔离 HEAD 运行失败测试。

### 假设

1. 陈述：desktop hosted adapter 未接入既有 owner 契约。
   预测：viewport state 未进入 binding；hosted owner 默认 true；input/resize/Force/visibility 生命周期无门禁。
   判别实验：追踪 protocol -> RemoteController -> RuntimeTerminalController -> TerminalSessionBinding -> render/input/resize；运行隔离 binding 测试。
   结果：全部命中；两条 production seam 测试失败。
   状态：confirmed
2. 陈述：host/mobile owner 契约本身缺失或错误。
   预测：mobile 不按 `remote:<device_id>` 与 host state 门禁，或缺 Auto/Force/Renew/Release。
   判别实验：读取 current mobile/host 实现及现有 viewport tests。
   结果：current 实现具有权威 state、identity、generation 与四种生命周期命令；反驳。
   状态：rejected

### 根因

## 修复

### 修复 Gate（L2）

#### 根因

因果链：desktop hosted adapter 丢失 host viewport state 与 identity，导致 binding 在未知/其他 owner/Error 时仍授权 render/input/resize。
first-wrong condition：managed attach 初始状态被 `unwrap_or(true)` 解释为 owned。
证据等级：A

#### 授权修复

因果单元：让 desktop hosted adapter 通过同一 per-session terminal stream 接收 host authority，并由 `TerminalSessionBinding` 统一门禁 render/input/resize 与 owner 生命周期。
owner：host state 是实际权威；`TerminalSessionBinding` 是 desktop “当前能否交互”问题唯一语义 owner；generation/connection epoch 仅协调。
生产机制：扩充既有 terminal lane；统一 runtime terminal stream callback；binding 保存最小 managed state并拒绝陈旧事件；view 连接 Auto/Release/8 秒 Renew，输入不再隐式 Force。
当前失败证据绑定：隔离 HEAD 两条失败测试直接覆盖 managed attach 初始 owner 与 input/resize 泄漏。
为何最小充分：复用现有 `TerminalEvent::Viewport`、`TerminalUiEvent`、handoff placeholder、`set_render_visible()` 与 runtime controller；不新建模块或第二状态源。

### 对抗性审查

- 疑点：binding callback 最终分别投递 output/UI channel。结论：非阻断；authority 在统一 callback 内同步更新并完成 generation/epoch gate 后才投递 UI，render/input/resize 不读取 UI queue；output 缓存与 authority 无第二判权。

- 疑点：unmanaged WSL 行为变化。结论：非阻断；无 identity 即无 authority，input/resize 与 legacy output/events adapter 保持原路径；回归测试覆盖。
