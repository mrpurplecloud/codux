### 目标

重新进入手机或桌面 Codux，激活本设备上次最后工作的项目。用户已用“ok”批准独立记忆方案，连接 headless 与桌面主机均适用。手机冷启动有有效记忆时直接显示该项目工作区；前后台切换保留当前项目；无记忆保持设备首页；已删除项目沿既有列表选择规则处理。

### 证据

桌面 project_actions/selection.rs 已通过 RuntimeService.select_project 写入 ProjectStore.selectedProjectId；runtime_state/loaders.rs 及 app_runtime_ready 从该字段恢复，未发现本任务需要的新桌面机制。remote/host/tests/projects.rs 已明确远程选择不改变桌面选择。手机 StorageService 仅保存项目列表，bootstrap.dart 显式 _showTerminal=false；Rust restore_cached_projects 选首项，selected_project_from_list 在无 pending/session 时优先主机选择。既有 userSelectProject + pending_project_select + protocol-ready 驱动已实现本地选择优先与重发，可直接复用。基线 Flutter 68 passed，desktop startup 1 passed。

### 授权变更

StorageService 新增按 hostId 保存/读取最后工作项目 ID；保留原项目缓存格式。工作区进入及实际项目切换在现有 HomeController 同步点保存。启动缓存恢复借助 userSelectProject 建立 pending intent，并打开工作区。连接启动等待缓存恢复，复用现有 generation/epoch 防止过期恢复发布。只提升 mobile 版本 beta.15+64 至 beta.16+65；记录兼容性边界。桌面仅补充/运行恢复验证，不改生产行为。

### 范围

owner / invariant：HomeController 拥有手机工作区意图；StorageService 保存每个 host 的最后工作项目；RemoteRuntimeModel 继续独占选择/确认/重发规则。重新进入恢复最后工作项目，过期缓存读取不得覆盖更新的设备或用户选择。
allowed_files：apps/mobile/lib/services/storage_service.dart；apps/mobile/lib/screens/home/state/{bootstrap,connection,sync,actions}.dart；apps/mobile/test/{storage_service_test,widget_test}.dart；apps/desktop/runtime/src/runtime_state/service_core_tests/project_activation.rs；apps/mobile/pubspec.yaml；docs/version-compatibility.md；本任务文件。
out_of_scope：跨设备同步、终端/工作树会话持久化重构、项目排序、断线退出工作区的既有行为、桌面持久化并发优化、推送、用户设备安装、发布、后续构建。

### 现有正确路径证据

reuse_decision：extend-existing StorageService 与缓存恢复；reuse Rust userSelectProject、pending selection、existing generation/epoch、desktop 恢复。

### 设计

owner：HomeController / StorageService / RemoteRuntimeModel，职责如上。
invariant：最后工作项目按设备和 host 隔离；更新用户选择优先于陈旧恢复与主机列表。
selected_design：上述授权变更。
acceptance_binding：保存服务对应跨进程记忆；bootstrap 对应自动打开；userSelectProject 对应主机不覆盖；await + existing generation/epoch 对应异步恢复顺序。
why_minimal_and_sufficient：复用现有缓存与 pending intent，未引入新状态机、FFI 或额外选择 owner。
alternatives：跨设备共享主机 selectedProjectId 已存在，但违反独立记忆及 desktop remote scope 既有契约，排除。
interface：仅新增手机内部存取方法，无 wire/FFI 修改。
data_model：新增可选 preference key，hostId 作用域；原列表缓存/配对数据不修改格式。
compatibility：无新字段时保持原首次启动；desktop/headless 不需要升级。
migration：无需数据迁移；旧键仍可读。
feature_flag：none。
rollback：回退手机代码/版本，新 preference 无破坏性影响。
verification_only：缓存读取与重连/用户选择竞争；保存失败；未连接真实手机。
out_of_scope：同 Active Contract。
