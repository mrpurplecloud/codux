# 任务

ID: agent-session-badges
类型：feature
状态：active
创建：2026-10-21

一句话描述：统一本地和远程项目的 Agent 会话状态，让用户一眼识别工作中、明确待介入和普通空闲。

## 等级

grade：Guarded
依据：跨共享运行时、远程协议和桌面 UI；涉及多会话聚合、连接重建、实例身份和独立产品兼容。
升级触发证据：none

## Active Contract

state：frozen；当前有效契约为原基础目标加已批准 revision 3/4；原目标 4 的“不新增面板或窗口”已由 revision 3 的独立会话总览替代。

### 目标

1. 本地与远程项目使用相同的会话状态含义；普通 shell 不冒充 Agent。
2. 区分工作中、明确待用户输入、空闲、无 Agent 和未知。回合结束不自动表示待输入、任务完成或应该退出进程。
3. 同项目任一会话有明确用户待办时优先提示；空闲不掩盖其他工作中会话。
4. 所有确实待用户输入的情况使用同一色系；复用项目角标和终端列表标识，不新增面板或窗口状态栏。
5. 已连接的远程项目无需先打开终端即可显示状态；首次连接、重连、后台变化及会话关闭后都应收敛到当前事实。
6. 彩墨屏下不依赖动画或颜色单独辨识；具体尺寸和配色需通过静态样稿及实机验收。
